CLI

Interface de Linha de Comando

Permite que o usuário controle um sistema digitando comandos textuais em um terminal.

Como funciona

O usuário informa um comando seguindo uma sintaxe específica. O sistema interpreta a instrução, executa a operação e apresenta o resultado em texto.

Comandos podem ser combinados em scripts para automatizar sequências de tarefas e repetir processos com precisão.

Principais características

  • Entrada e saída predominantemente textuais.
  • Sintaxe e parâmetros bem definidos.
  • Composição e automação de comandos.
  • Operação completa por teclado.

Exemplos de utilização

Prompt de Comando, PowerShell, Bash, Terminal Linux, Git e ferramentas de administração de servidores utilizam interfaces de linha de comando.

O PowerShell é um exemplo de CLI. O usuário digita comandos e o sistema apresenta os resultados em formato textual.

Vantagens e limitações

+

Vantagens

  • Execução rápida.
  • Automação de tarefas.
  • Baixo consumo de recursos.
  • Controle detalhado.
  • Repetição de operações.
!

Limitações

  • Exige conhecimento técnico.
  • Requer memorização.
  • Erros de digitação impedem ações.
  • Mensagens podem confundir iniciantes.
A

Cuidados de acessibilidade

O terminal precisa oferecer contraste ajustável, textos claros e navegação integral por teclado. A saída deve manter uma ordem compreensível para tecnologias assistivas.

Mensagens de erro devem identificar o problema e sugerir uma correção, evitando depender apenas de códigos ou mudanças de cor.

Fonte científica utilizada

SCHRÖDER, Michael; CITO, Jürgen. An empirical investigation of command-line customization. Empirical Software Engineering, v. 27, 2022.
